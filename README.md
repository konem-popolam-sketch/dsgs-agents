# Доска студии DSGS

Публичный снимок внутренней доски: 50 ролей игровой студии, у каждой свой портрет,
рабочая форма и статус из трёх — работает / ждёт / отдыхает.

Открывается как обычный статический сайт, без сборки и сервера.

## Что внутри

| Путь | Что это |
|---|---|
| `index.html` | вся страница: разметка, стили и снимок статусов одним файлом |
| `avatars/anime/` | 50 портретов + 50 «спящих» + 50 полос рабочей анимации |
| `avatars/kakamora/` | альтернативный стиль, 50 портретов |

Переключатель стилей — в шапке страницы, выбор запоминается в localStorage.

## Про статусы

Это **снимок**, а не живая доска. Статусы зафиксированы на момент сборки;
живая версия обновляется локально из `.agent-teams/` и закрыта для публики.

## Пересобрать

```sh
python tools/studio-board/build_studio_board.py   # пересобрать docs/studio-board/index.html
node tools/build-publish-board.mjs                # пересобрать этот каталог
```
